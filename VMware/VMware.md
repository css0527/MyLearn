# Install

## 访问 Broadcom 支持门户：
-先注册一个免费的 Broadcom 基础账号（Basic Account）。注册时信息最好填写准确，否则可能会影响后面的下载验证
-登录后，访问 "My Downloads" 下的 "Free Software Downloads"

## 找到安装包VMware-workstation-full-17.6.2-24409262. exe：
在产品列表里找到 VMware Workstation Pro。
选择对应的 Windows 版本和 17.6.2 版本，就可以下载了
